A modern, responsive homepage for a fictional IELTS Institute, built using **React JS** and **Tailwind CSS**.  
This project focuses on **design, UI quality, and responsiveness**, showcasing a professional educational website layout.

🚀 Features

- **Responsive Navbar** with clickable logo
- **Hero Section** with headline, subtext, CTA button, and icons
- **Why Choose IELTS Section** with feature cards and icons
- **Student Testimonials** with avatars and review cards
- **Footer** with basic links and contact info
- Fully responsive and mobile-friendly design
- Clean and modular React component structure
